# Sistema de Chamados — HelpDesk Portfolio Gestão em TI

Esse é meu terceiro projeto de desenvolvimento web, e o mais completo até agora.

Sou estudante de Gestão em TI e esse projeto nasceu da vontade de entender
na prática como funcionam os sistemas de suporte técnico usados por times de
TI no dia a dia. Ferramentas como Zendesk e ServiceNow fazem isso em escala
— aqui entendi a lógica por trás delas.

## Acesse o Projeto

[Clique aqui para acessar](https://matheusgrun5.github.io/sistema-chamados/)

## Observação

O sistema usa localStorage para salvar os dados no navegador.
Ao acessar pela primeira vez a lista estará vazia — isso é intencional.
Você pode testar abrindo novos chamados e usando todas as funcionalidades.

## O que foi usado

- HTML5 — estrutura do sistema
- CSS3 — visual estilo Zendesk, claro e corporativo
- JavaScript — lógica completa do sistema
- localStorage — persistência de dados no navegador
- jsPDF — exportação de relatórios em PDF
- SheetJS — exportação de planilhas Excel

## O que o projeto faz

- Abertura de chamados com protocolo automático
- Categorização por tipo — Hardware, Software, Rede, Acesso
- Priorização — Baixa, Média, Alta e Crítica
- Controle de status — Aberto, Em Atendimento e Resolvido
- SLA por prioridade com alerta visual quando crítico
- Modal de detalhes completos do chamado
- Registro de comentários por chamado com horário
- Filtros por status e prioridade
- Busca por protocolo ou solicitante
- Paginação com 10 chamados por página
- Exportação de relatórios em PDF e Excel
- Dashboard com métricas em tempo real
- Menu lateral com navegação entre seções
- Deploy com HTTPS via GitHub Pages

## Conexão com Gestão em TI e ITIL

Sistemas de chamados são o coração da Gestão de Serviços de TI.
Este projeto conecta diretamente com os processos de Gestão de
Incidentes, Gestão de Requisições e Gestão de SLA do framework ITIL.
